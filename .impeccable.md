# Design Context — Helm

## Product
A security-focused desktop control center (Electron + React) for managing many
accounts across AI/dev platforms (Google, GitHub, OpenAI, Anthropic, Cursor,
Windsurf, X, YouTube…). Core jobs: store/organize credentials securely, manage
2FA, audit security, run and monitor browser automation (login, change
password/recovery, batch registration), and give each account an isolated Chrome
profile with its own proxy + browser identity (anti-detect).

## Target audience
Power users — indie developers, growth/marketing operators, researchers — who
juggle dozens of accounts and need control, safety, and speed. Comfortable with
technical density; value scanability over hand-holding.

## Use cases
- Securely store & organize many accounts (groups, tags, search, bulk edit).
- Run & monitor automation with clear before/after results and step logs.
- Manage 2FA (import from / export to Google Authenticator).
- Audit security (weak/reused/breached passwords, missing 2FA/recovery).
- Configure providers (mailbox/captcha/sms/proxy) and per-account identities.
- One-click open an account's isolated browser.

## Brand personality / tone
Mission-control "vault": calm, dense-but-legible, trustworthy, precise. Dark-first
with an indigo primary and restrained accents. NOT playful, NOT neon-glow.
Clarity and hierarchy over decoration.

## Differentiation (the memorable thing)
It feels like a cockpit for account operations — security posture, automation
status, and per-account identities are visible and actionable at a glance, with an
isolated browser for any account one click away.

## Design guardrails (project-specific)
- Keep the existing token system (semantic HSL + dark mode). Tint neutrals toward
  the indigo brand hue; never pure black/white.
- Reserve monospace for real machine values (secrets, UA, IPs, codes, logs).
- Consistent primitives: PageHeader, EmptyState (teaches next action), Skeleton
  loaders, section headers. Don't nest cards; not everything needs a card.
- Hierarchy of buttons: one primary per context; others outline/ghost.
- Motion: subtle fade/slide on mount and state changes; transform/opacity only.
